# Learning about Version Control
Authored by Everett Rendon

Solving merge conflicts takes conscious effort, but I can do it!

I like the general workflow of version control - working independently on a portion and requesting that it be merged into the main, which remains untouched in the meantime.

The thing I find most frustrating about it is how clunky the way that you have to manually resolve the merge conflicts feels. I know that it'll get easier with practice but it doesn't feel great to do when just starting out.
